The following keywords cannot be used as names for datasets.

## General Protected Keywords

These keywords apply to all data connectors:

- `COUNT`
- `FALSE`
- `NULL`
- `END-EXEC`
- `LATERAL`
- `TABLE`
- `UNNEST`

## Connector-Specific Protected Keywords



# API keys

Each Spice app have two pre-generated API keys, which can be used with Spice SDKs, the [HTTP API](../../api/sql-query/http-api.md) or the [Apache Arrow Flight API](connect-github.md).

![image](/img/cloud/CleanShot 2024-12-27 at 10.13.35@2x.png)

* Select Spice app and navigate to **Settings** -> **General.**
* Click the **API Key 1** or **API Key 2** field to copy the key value.
* You can regenerate each key if you need to invalidate it.

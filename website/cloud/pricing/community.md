# Community Plan

The Community Plan provides one free Spice application per organization.

### Inactivity Auto-Pause

Applications that remain inactive for 7 days are automatically paused.

Paused applications can be restored through the portal at any time. An application is considered active on a given day if it receives at least one API request using its API key.

[Paid plans ](plans.md)do not auto-pause.
